# AI-guide-book

这是一个面向 AI 工具学习者与实践者的指南项目，旨在帮助大家更高效、更清晰地理解和使用各类 AI 工具。

项目会围绕常见的 AI 使用场景，整理实用的方法、案例和经验，包括但不限于：

- 如何选择适合自己的 AI 工具
- 如何编写更有效的提示词
- 如何把 AI 用在学习、办公、创作和开发中
- 如何理解 AI 工具的能力边界与注意事项
